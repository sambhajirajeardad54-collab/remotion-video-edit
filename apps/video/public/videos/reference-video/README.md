# Reference video (editing-style examples)

Put videos here whose **editing style** you want to copy: transitions,
animations, typography, camera framing, captions, sound effects and motion
graphics.

- These are for analysis only. They are NEVER used as footage or audio in
  your videos: `src/workflow/media.ts` gives them a separate type, so code
  that tries to use one as video or voiceover fails with an error.
- Analyse one with `scripts/workflow/analyze-reference.sh <file>`.
- Video files here are NOT committed to GitHub (see `.gitignore`).
